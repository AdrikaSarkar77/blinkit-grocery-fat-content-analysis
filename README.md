# 🛒 Blinkit Grocery Fat Content Analysis Dashboard

## 📌 Project Overview
This project analyzes Blinkit's grocery sales data focusing on fat content, outlet performance, and customer behavior using Power BI.

The goal is to extract actionable insights that help improve product strategy, sales optimization, and outlet performance.


---

## 🛠 Tools & Technologies
- Power BI
- Excel / CSV
- Data Cleaning & Transformation
- Data Visualization

---

## 📊 Key Business Insights
- 🟡 Low-fat products generated higher overall revenue compared to regular items
- 🏬 Tier 3 outlets contributed the highest sales ($472K+)
- 📈 Peak outlet establishment growth observed around 2018
- 🥇 Supermarket Type 1 dominates in total sales and item count
- ⭐ Average customer rating remains consistent (~3.9)
